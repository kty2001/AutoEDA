## 1. 지금 어디인가

**Phase 1 런타임 코드가 닫힘. 브라우저에서 한 번도 돌려보지 않은 상태임.**

CSV를 읽어 통계·품질 점수·발견 목록·차트까지 만드는 경로가 전부 구현되어 있고 `npm test` 188건이 통과함. 다만 Node 테스트는 Worker 기동·실제 CSP·드래그 앤 드롭·sessionStorage 왕복을 검증하지 못하므로, **실기 확인 전까지 "동작한다"고 말할 수 없음.**

| 지표 | 값 |
|---|---|
| 런타임 코드 | `js/` 18개 모듈 (스텁 0) |
| 테스트 | 188건 통과 (계약 21 + 동작 167) |
| 남은 스텁 | 빌드 스크립트 3종 |
| 미발행 콘텐츠 | 해설 22편 · 사례 6편 (전부 미착수) |

## 2. 다음 작업

### T1. 브라우저 실기 검증 ← **지금 할 것**

`npm run serve` 후 `http://localhost:8000/pages/analyze.html`. Node 테스트가 대신할 수 없는 유일한 영역이므로 빌드 스크립트보다 먼저 함 — 여기서 결함이 나오면 app 배선을 고쳐야 하고, 그 상태로 콘텐츠 작업에 들어가면 되돌릴 것이 늘어남.

**확인 항목** — 하나라도 실패하면 그 자리에서 고치고 [`work-log.md`](work-log.md)에 기록함.

- [ ] 파일 선택 → 진행률 5단계 표시 → 결과 화면 전환
- [ ] 드래그 앤 드롭으로도 같은 경로 동작
- [ ] 5탭 전환(개요·품질·발견·변수별·관계)과 탭 선택이 새로고침 후에도 유지됨(`autoeda:prefs`)
- [ ] 차트가 실제로 그려짐 — **CSP 위반 콘솔 오류가 없을 것** (인라인 style 금지 준수 확인)
- [ ] 개요 탭에서 열 타입 변경 → 전체 재계산 → 결과 갱신
- [ ] 진행 중 취소 → 상태 A 복귀, 부분 결과가 남지 않음
- [ ] 결과 내보내기 → 그 파일을 불러오기로 복원
- [ ] 해설 링크(`자세히 →`)를 눌러 이탈 후 뒤로가기 → 결과 복원
- [ ] 결과 지우기 → 새로고침 시 `이어보기`가 사라짐
- [ ] 오류 4유형: EUC-KR 파일 강제 실패 시 인코딩 수동 선택 / 25MB 초과 / 열 수 어긋난 CSV / 잘못된 JSON 불러오기
- [ ] 한글 열 이름 CSV와 CP949 저장 파일이 깨지지 않음

**준비물**: 테스트용 CSV 몇 개(UTF-8 한글, CP949 한글, 열 수 불일치, 대용량). `tests/integration.test.js`의 픽스처 생성 코드를 재사용하면 만들 수 있음.

### T2. 빌드 스크립트 3종

각 파일 헤더의 TODO 목록이 명세임. 셋 다 **서식 오류 시 파일을 쓰지 않고 exit 1** ([`implementation-status.md` §2](implementation-status.md) 규약 7).

1. `scripts/build_seo.mjs` — 먼저 함. 콘텐츠가 없어도 기존 페이지에 canonical·OG·JSON-LD를 주입하고 sitemap을 만들 수 있어 **배포(T3)의 선행 조건**임. URL은 확장자 없이

구현하며 미뤄 둔 판단들. 실사용 데이터가 있어야 결론이 나므로 T1 이후에 봄.
