# 데이터셋 이용 조건 검토

- 작성일: 2026-08-16
- 전제: [`content-strategy.md §2.6`](./content-strategy.md) 사례 리포트 6편, [`content-strategy.md §4`](./content-strategy.md) 광고 게재 정책
- **이 문서가 단일 원천인 것**: 사례 리포트에 쓸 데이터셋의 이용 조건 판정과 표시 요건
- **상태: 절차·기준 확정, 개별 데이터셋은 전부 미판정.** §7 참조

> 이 문서는 일반적인 이용 조건 정리이며 법률 자문이 아님.

---

## 1. 이 검토가 필요한 이유

**광고 게재는 상업적 사용임.** 사례 리포트 6편은 공개 데이터셋을 분석해 발행하고, 그 페이지에는 광고가 붙음([`content-strategy.md §4`](./content-strategy.md)). 비상업 조건의 데이터를 쓰면 AdSense 심사를 통과한 뒤에도 정책 위반이 됨 — Google Publisher Policies가 저작권 침해 콘텐츠에 광고를 게재하는 것을 금지하며, 계정 정지·수익 몰수 리스크가 따름.

`../../Documents/project_process.md` §6이 이를 명시함: **"광고 게재는 상업적 사용이다. 비상업 조건의 API/데이터를 쓰고 있다면 심사 통과 전에 정리한다."**

### 형제 프로젝트 선례 2건

| 프로젝트 | 판단 |
|---|---|
| `BDAnalyzer` | 기출문제 수록의 법적 리스크를 검토한 뒤 **"직접 창작한 오리지널 예상문제만"으로 데이터 출처를 제한.** 2024년 대법원이 무료·공익 목적 공개조차 공정이용으로 보지 않은 판례를 근거로, 영리 목적인 AdSense에서는 훨씬 불리하다고 판단 |
| `weareants` | **"무료는 이용 요금 기준일 뿐 재배포 가능 여부는 별개"** 라는 판단으로 후보를 갈랐음. 계좌 보유자 대상 증권사 API는 광고 수익 사이트 재배포 허용 여부가 불분명하고 스크래핑은 ToS 위반 소지가 있어, 공공데이터포털(이용허락범위 "제한 없음")로 확정 |

두 프로젝트 모두 **착수 전에** 이 검토를 거쳤음. AutoEDA는 사례 리포트를 Phase 1.5 완료 조건으로 두고 있으므로 그 전에 판정이 끝나야 함.

## 2. 완화 요소 — 원본을 재배포하지 않음

**사례 리포트는 원본 데이터를 사이트에 올리지 않음.** 집계 통계와 해석만 게시하며, 이는 결과 JSON이 원본 행을 담지 않는 규약([`data-model.md §3`](./data-model.md))과 같은 성격임. 원본 CSV 파일을 다운로드 제공하지 않고, 미리보기 행도 게시하지 않음.

이로써 라이선스 조항 중 **재배포 관련 제약의 상당 부분을 회피함.**

| 조항 | 본 프로젝트 적용 여부 |
|---|---|
| 재배포 금지·제한 | **해당 없음** — 원본을 배포하지 않음 |
| **상업적 이용 금지** | **해당됨** — 광고 게재는 상업적 사용 |
| **출처 표시 의무** | **해당됨** — 재배포 여부와 무관 |
| **변경(파생물) 금지** | **해당됨** — 분석 결과는 파생물로 볼 수 있음 |

따라서 판정은 **상업적 이용 / 출처 표시 / 변경 허용** 세 축으로 좁혀짐. 재배포 조항만 있는 라이선스는 문제가 되지 않음.

## 3. 판정 항목

데이터셋마다 아래 7항목을 확인해 표로 채움.

| 항목 | 확인 내용 |
|---|---|
| 출처 URL | 배포판을 하나로 확정. 여러 곳에 있는 데이터셋은 어느 판을 쓰는지 명시 |
| 라이선스 | 이름과 전문 URL |
| 상업적 이용 | 허용 / 금지 / 불명확 |
| 출처 표시 의무 | 있음 / 없음. 있으면 표기 문구 |
| 변경(파생물) 허용 | 허용 / 금지 / 불명확 |
| 원본 재배포 | 본 프로젝트는 **항상 "안 함"** (§2) |
| 판정 · 확인일 | 사용 가능 / 조건부 / 불가 + 확인한 날짜 |

**불명확은 불가로 취급함.** 확인되지 않은 조건을 낙관적으로 해석하지 않음.

## 4. 데이터셋별 체크리스트

[`content-strategy.md §2.6`](./content-strategy.md)의 사례 6편에 대응함. **전부 미판정 상태이며 아래는 확인해야 할 쟁점임.**

### C1 Titanic

| 항목 | 상태 |
|---|---|
| 출처 URL | **미확정 — 배포판을 골라야 함** |
| 쟁점 | 원 데이터는 1912년 승객 기록이라 사실 자체에는 저작권이 미치지 않지만, **배포판마다 조건이 다름.** 경진대회 플랫폼판은 대회 규정이 적용될 수 있고, 통계 소프트웨어 내장판·공개 데이터 저장소판은 각자의 라이선스를 가짐. 어느 판을 쓰는지에 따라 판정이 갈림 |
| 확인 순서 | 후보 배포판을 나열 → 각 라이선스 전문 확인 → 상업적 이용이 명시적으로 허용된 판을 선택 |

### C2 House Price

| 항목 | 상태 |
|---|---|
| 출처 URL | **미확정** |
| 쟁점 | Ames Housing 데이터. **논문 부속 원 데이터와 경진대회판이 다름.** 원 출처의 이용 조건을 확인해야 하며, 경진대회판을 쓰려면 그 규정을 따라야 함 |

### C3~C6 국내 공공데이터 3~4건

| 항목 | 상태 |
|---|---|
| 데이터셋 | **미선정** |
| 쟁점 | 공공데이터포털의 **이용허락범위**를 데이터셋마다 확인해야 함. 포털에 있다는 사실만으로 조건이 같지 않음 |
| 판정 기준 | `제한 없음` → 사용 가능 / `출처표시` → 표시로 충족(§6) / **`변경금지` → 후보에서 제외** (분석·파생 결과 게시가 걸릴 수 있음) / `상업적 이용금지` → **제외** |

국내 데이터는 `content-strategy.md §2.5`의 K3(한국 공공데이터 전처리 함정)와 상호 링크되므로 **실제로 지저분한 데이터**를 고르는 것이 콘텐츠 가치에 유리함. 다만 조건 판정이 우선임.

> **판정이 끝나지 않은 데이터셋은 사례 리포트로 만들지 않음.** 작성 순서([`content-strategy.md §8`](./content-strategy.md))에서 사례는 3순위이므로 그 전에 판정할 시간이 있음.

## 5. 판정 실패 시 대체 후보

| 후보 | 평가 |
|---|---|
| 조건이 명확한 다른 공개 데이터 | **1순위.** CC0, 공공누리 제1유형 등 상업적 이용이 명시적으로 허용된 것 |
| 자체 생성 합성 데이터 | 라이선스 리스크 0이고 "이 사이트에만 있는 데이터"라는 유효 패턴에도 부합함. 다만 **실제 데이터의 지저분함을 보여주는 것이 사례의 핵심 가치**이므로 차선임 — 합성으로 만들려면 결측·이상치·인코딩 문제·단위 혼재를 의도적으로 심고, **합성 데이터라는 사실을 페이지에 밝혀야 함**(실제 데이터로 오인시키면 안티패턴에 해당) |

## 6. 표시 요건

각 사례 페이지에 아래를 명기함. [`screens.md §3.5`](./screens.md)가 "데이터셋 설명·출처·이용 조건"을 초기 HTML 필수 항목으로 요구하는 근거가 이 절임.

- 데이터셋 이름과 **출처 URL**
- 라이선스 이름 (+ 전문 링크)
- 출처 표시 의무가 있으면 요구된 표기 문구 그대로
- **이용 조건 확인일**
- 원본 데이터를 재배포하지 않는다는 사실 (§2)
- 합성 데이터인 경우 그 사실

## 7. 미확인 항목과 확인 절차

**이 문서 작성 시점에 개별 데이터셋 판정은 전부 미완료임.** 절차와 기준만 확정했음.

### 확인 절차

1. 원 출처 페이지에서 배포판을 확정함
2. 라이선스 **전문**을 확인함 — 요약이나 제3자 설명에 의존하지 않음
3. §3의 7항목을 표로 채움
4. 상업적 이용이 명시적으로 허용되지 않으면 **후보에서 제외함** (불명확 = 불가)
5. 확인일을 기록함. 조건은 변경될 수 있으므로 사례 발행 시점에 재확인함

### 남은 불확실성

| 항목 | 내용 |
|---|---|
| 배포판 선택 | C1·C2는 어느 배포판을 쓸지 미정. 선택에 따라 판정이 달라짐 |
| 국내 데이터셋 선정 | C3~C6의 대상 미선정 |
| "변경금지"의 해석 범위 | 집계 통계 산출이 "변경"인지에 대한 해석 여지가 있음. **보수적으로 제외**하는 것을 원칙으로 함 |
| 전문가 확인 | 형제 프로젝트도 남긴 항목임. 수익화 직전 필요 시 한국저작권위원회 무료상담 등을 고려함 |
