파일과 형식

어떤 파일을 지원하나요?

CSV를 지원합니다. 구분자(쉼표·세미콜론·탭·파이프)는 자동으로 추정하고, UTF-8과 CP949·EUC-KR 인코딩을 자동으로 감지하므로 한글 컬럼명이 깨지지 않습니다. 자동 감지가 실패하면 인코딩을 직접 고를 수 있습니다.

Excel 파일은 열 수 없나요?

아직 지원하지 않습니다. Excel에서 “다른 이름으로 저장 → CSV”로 저장한 뒤 사용해 주세요. 한글이 들어 있다면 CSV UTF-8 형식으로 저장하는 편이 안전합니다.

얼마나 큰 파일까지 분석할 수 있나요?

파일 크기는 25MB까지입니다. 분석이 브라우저 메모리에서 이루어지므로 기기 사양에 따라 그보다 작은 파일에서도 느려질 수 있습니다.

개인정보와 처리 방식

데이터가 서버로 전송되나요?

아니요. 분석은 브라우저에서만 실행되며 파일은 어디에도 저장되지 않습니다. 분석이 끝나면 집계된 통계만 현재 탭에 임시로 남고, 탭을 닫으면 사라집니다.

회원가입이 필요한가요?

필요하지 않습니다. 계정도, 파일을 올릴 서버도 없으므로 페이지를 열고 파일을 고르면 바로 분석이 시작됩니다.

분석 결과를 지울 수 있나요?

결과 화면의 “결과 지우기”로 브라우저에 남은 결과를 즉시 삭제할 수 있습니다.

결과 읽기

품질 점수는 어떻게 계산되나요?

100점에서 결측·중복·상수 컬럼·고카디널리티·이상치 항목별로 감점한 값입니다. 점수는 전체 상태를 한눈에 보기 위한 요약이고, 무엇을 고쳐야 하는지는 발견 목록에서 확인합니다.

열의 타입을 잘못 인식하면 어떻게 하나요?

개요 화면에서 열의 타입을 직접 바꿀 수 있고, 바꾸면 관련 분석이 다시 계산됩니다. 우편번호나 코드값이 수치로 인식되는 경우에 사용하세요.

발견 목록에 나온 조치를 그대로 따라야 하나요?

아니요. 제시되는 조치는 통계적 특징에 근거한 검토 대상이지 정답이 아닙니다. 어떤 이상치가 오류이고 어떤 것이 실제 현상인지는 데이터가 무엇을 재는지 아는 사람만 판단할 수 있습니다. 각 발견의 “자세히” 링크에서 판단 근거를 확인할 수 있습니다.

전처리와 타깃

이상치 제거나 스케일링을 여기서 바로 할 수 있나요?

결과 화면의 전처리 탭에서 중복 행 제거, 결측 대치, 이상치 처리, 로그 변환, 범주 인코딩, 스케일링을 골라 적용하고 정제된 CSV를 내려받을 수 있습니다. 적용 전후의 품질 점수와 열별 분포 변화를 나란히 보여 주며, 원본 파일은 바뀌지 않습니다.

타깃 열을 지정하면 무엇이 달라지나요?

개요 화면 상단에서 예측하려는 열을 타깃으로 지정하면 전체를 다시 계산하고 타깃 탭이 열립니다. 회귀 타깃(수치형)이면 타깃 분포와 피처별 상관 순위를, 분류 타깃(범주형·불리언)이면 클래스 분포와 클래스별 수치 요약을 보여 주며, 클래스 불균형·타깃 왜도·데이터 누수 발견도 함께 나타납니다.

모델 학습까지 해 주나요?

아니요. 이 사이트는 모델링 전 단계인 데이터 이해(EDA)와 전처리를 맡습니다. 정제한 CSV와 발견 목록을 가지고 사용하는 분석 환경에서 모델링을 이어 가면 됩니다.

저장과 공유

결과를 보관할 수 있나요?

결과를 JSON 파일로 내보내고 도구 화면의 “저장한 결과 불러오기”로 다시 열 수 있습니다. 집계 통계와 발견만 담기며 원본 데이터 행은 포함되지 않습니다.

요약만 링크로 공유할 수 있나요?

결과 화면의 “요약 공유 링크 복사”를 누르면 품질 점수와 주요 발견 상위 3건만 담은 링크가 클립보드에 복사됩니다. 이 링크는 서버에 아무것도 저장하지 않고 URL 안에만 정보를 담으며, 받은 사람은 파일을 올리지 않고도 요약을 볼 수 있습니다.
