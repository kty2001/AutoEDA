이 도구가 하는 일

CSV의 각 열이 어떤 종류의 데이터인지 판별하고, 결측·중복·이상치·상수 컬럼 같은 품질 문제를 찾아 점수로 집약합니다. 이어서 확인해야 할 사항을 발견 목록으로 정리하고 각 항목에 무엇이 발견되었는지, 왜 문제인지, 무엇을 하면 되는지를 함께 제시합니다.

지원 형식과 인코딩

CSV를 지원하며 구분자(쉼표·세미콜론·탭·파이프)를 자동으로 추정합니다. 인코딩은 UTF-8을 먼저 시도하고 실패하면 EUC-KR로 해석하므로 CP949로 저장된 한글 파일도 열립니다. 자동 감지가 실패하면 인코딩을 직접 고를 수 있습니다.

처리 방식

파일은 서버로 전송되지 않고 브라우저 메모리에서만 처리됩니다. 분석이 끝나면 집계된 통계만 현재 탭에 임시 보관되며(탭을 닫으면 사라집니다) 원본 데이터는 어디에도 저장되지 않습니다. 해설을 보러 다른 페이지에 갔다 돌아오면 결과가 그대로 남아 있습니다.

한계

  • 브라우저 메모리에서 처리하므로 아주 큰 파일은 열 수 없습니다.
  • Excel 파일은 아직 지원하지 않습니다. CSV로 저장한 뒤 사용해 주세요.
  • 통계적 특징을 알려주는 도구이며, 도메인 지식이 필요한 판단은 대신하지 않습니다. 제시되는 조치는 검토 대상이지 정답이 아닙니다.
  • 결측이나 이상치를 자동으로 고치지 않습니다. 원본을 수정하지 않는 것이 원칙입니다.

자주 묻는 질문

결과를 다른 사람에게 보여줄 수 있나요?

결과를 JSON 파일로 내보내 전달하면 상대가 이 화면에서 불러와 같은 결과를 볼 수 있습니다. 집계 통계와 발견만 담기므로 원본 데이터는 전달되지 않습니다.

열의 타입을 잘못 인식하면 어떻게 하나요?

개요 화면에서 열의 타입을 직접 바꿀 수 있고, 바꾸면 관련 분석이 다시 계산됩니다. 우편번호나 코드값이 수치로 인식되는 경우에 사용하세요.

분석 결과를 지울 수 있나요?

결과 화면의 “결과 지우기”로 브라우저에 남은 결과를 즉시 삭제할 수 있습니다.
