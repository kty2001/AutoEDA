자주 묻는 질문

어떤 파일을 지원하나요?

CSV를 지원합니다. UTF-8과 CP949·EUC-KR 인코딩을 자동으로 감지하므로 한글 컬럼명이 깨지지 않습니다.

데이터가 서버로 전송되나요?

아니요. 분석은 브라우저에서만 실행되며 파일은 어디에도 저장되지 않습니다.

결과를 보관할 수 있나요?

결과를 JSON 파일로 내보내고 다시 불러올 수 있습니다. 집계 통계와 발견만 담기며 원본 데이터 행은 포함되지 않습니다.
